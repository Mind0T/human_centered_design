      Cómo está organizada la base de datos

      1 · Las páginas

      aterrizar, empatía y riesgo envían cada campo apenas lo escriben.

      →

      2 · Pestaña “Datos”

      Almacén crudo: una fila por campo (o por nota, evento o autorreporte). Lo usan las páginas; no está hecho para leerse.

      →

      3 · Pestañas legibles

      0 · LEEME, 1 · Aterrizar, 2 · Empatía, 3–5 · Riesgo, 6 · Insumos requerimientos. Se reconstruyen solas.
